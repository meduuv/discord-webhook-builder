# Discord Webhook Builder

A dependency-free browser tool for creating Discord webhook JSON payloads.

### Features
- Username and avatar fields
- Message content
- Basic embed title/description
- Live JSON preview
- One-click copy
- Fully local: no webhook URL and no data are transmitted

Open `index.html` and paste the generated JSON into your own authorized webhook workflow.

This tool intentionally does **not** execute webhooks.
